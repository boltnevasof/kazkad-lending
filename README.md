# Kazkad — лендинг

Одностраничный сайт студии на React + Vite. Вёрстка, токены и компоненты взяты
из дизайн-системы `Kazkad Design System/` (скилл Claude Design), поверх неё
добавлен моушен-слой: заставка, перелистывание разделов и слайдовый скролл.

## Запуск

Дев-режим с hot reload — http://localhost:5173

```bash
docker compose up --build
```

Прод-сборка за nginx — http://localhost:8080

```bash
docker compose -f docker-compose.prod.yml up --build
```

Порт на хосте переопределяется переменной `WEB_PORT`, например
`WEB_PORT=5174 docker compose up`.

Без Docker: `npm install && npm run dev`.

## Дизайн-система

`src/design-system/components/` и `tokens/` — дословная копия папки
`Kazkad Design System/`. Руками её не правим: при перегенерации системы файлы
перекладываются заново.

Два места, которые при копировании нужно поправить, — пути к ассетам, потому что
в React-сборке они лежат в `public/assets/`, а не рядом с CSS:

- `tokens/fonts.css` — `url("../assets/fonts/…")` → `url("/assets/fonts/…")`
- `tokens/colors.css` — `--glow-image` → `url("/assets/star-glow.png")`

Базы для ассетов, которые компоненты резолвят в рантайме (`Icon`, `Logo`,
`GlowBackdrop`), задаются в `index.html`: `KZ_ICON_BASE` и `KZ_ASSET_BASE`.

Анимированные версии шапки, кнопки и плитки кейса живут в `src/components/` —
у DS-версий оформление прибито inline-стилями, и перебить его из CSS нечем.
Геометрия и токены при этом те же, что в системе.

## Моушен

- **Заставка.** Чёрное полотно, по центру проявляется логотип, затем полотно
  расходится вверх и вниз и уносит логотип с собой — стык проходит ровно по его
  середине. Пока заставка идёт, страница не скроллится.
- **Перелистывание.** Клик по пункту меню поднимает четыре чёрные панели, под
  ними происходит мгновенный переход.
- **Шапка** зафиксирована (`position: fixed`) и лежит в корне страницы, а не
  внутри Hero: `sticky` обрезается предком с `overflow`, и шапка пропадала за
  пределами первой секции. Высоту шапки компенсирует отступ героя.
- **Активный раздел** в шапке держит синяя черта, которая переезжает от пункта
  к пункту; ink-подчёркивание осталось за наведением.
- **Скролл обычный.** Перехвата колеса и привязки к секциям нет — страница
  скроллится как всегда.
- **Заголовки** выезжают по словам из-под собственной строки.
- **Лента кейсов** без `scroll-snap`: с mandatory браузер пересчитывал точки
  привязки при каждой перерисовке плиток и уводил ряд к последней.
- **Всё выключается** при `prefers-reduced-motion: reduce`.

## Открытые вопросы

- Telegram, почта и телефон в `src/content/site.js` — заглушки из дизайн-системы.
- Кейсы используют изображения из концепта; нужны реальные скриншоты работ.
- Кнопка «все проекты» и фильтры по направлениям ждут отдельную страницу.
