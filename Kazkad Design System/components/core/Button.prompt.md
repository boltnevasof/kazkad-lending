The action control — blue fill for the single primary CTA, hairline outline for everything alongside it.

```jsx
<Button variant="primary" size="lg" icon="arrow-right">Обсудить задачу</Button>
<Button variant="secondary">посмотреть кейс</Button>
```

Variants: `primary` (blue #1763e6, darkens to #0f4bb8 on hover), `secondary`, `ghost`, `inverse` (on dark bands). Sizes sm/md/lg = 36/44/56px. Press state scales to 0.98 — never a colour flash.
