Monochrome Lucide glyph — the SVG file is fetched and inlined, so it inherits `currentColor` from its label.

```jsx
<Icon name="arrow-up-right" size={20} />
```

Set `window.KZ_ICON_BASE = '../../assets/icons/'` once per page (or pass `base`) so the mask URLs resolve. Available stems: arrow-right, arrow-up-right, arrow-left, check, x, plus, minus, chevron-down, chevron-right, menu, mail, phone, send, clock, zap, shield-check, code, layers, rocket, circle-check, circle-alert, info, star, external-link, file-text, users, trending-up, sparkles.
