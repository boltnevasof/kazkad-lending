Opens a section. The heading comes first — never put a small label above it.

```jsx
<SectionHeading title="Что мы уже запустили" label="кейсы" count={4} />
<SectionHeading title="21 день, разложенный по дням" lead="Дизайн и разработка идут внахлёст." />
```

`label`/`count` render inline after the heading, which is how the concept board sets "кейсы 4".
